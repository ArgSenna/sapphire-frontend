# 1. 每日消息面变化与影响分析

你是一位专业的股票研究分析师。请对股票 [股票代码/名称] 进行每日消息面变化分析。目标：让投资者每天早上快速掌握从昨日至今发生了哪些新的消息面变化，并理解这些变化对持仓的影响。

1. 公司层面消息：
   - 最新公告（财报、分红、增减持、股权变动、合同中标、产品发布等）
   - 管理层动态（高管变动、股东行为、战略调整等）
   - 与公司直接相关的媒体报道与市场传闻
2. 行业与政策层面：
   - 所属行业的新政策、监管动态、补贴或限制措施
   - 行业内竞争对手的重大动向（对标公司的财报、产品、并购等）
   - 上下游产业链的重要变化（原材料价格、供需关系等）
3. 宏观与市场环境：
   - 影响该股的宏观经济数据或政策信号（利率、汇率、贸易政策等）
   - 外围市场对该板块的传导影响（美股相关板块、港股联动等）
4. 影响研判：
   - 对每条消息标注【利好/利空/中性】及影响程度【高/中/低】
   - 综合判断：这些消息叠加后，对今日盘面可能产生的整体影响方向
5. 关注要点：今日开盘前最需要关注的 1-3 个核心信号

输出格式要求：按重要程度排列，每条消息附带影响判断，最后给出简明的综合研判。

# 2. 重大事件预测

你是一位擅长事件驱动分析的投资顾问。请对股票 [股票代码/名称] 进行未来重大事件预测分析：

1. 已确定事件日历：
   - 财报披露日、股东大会、限售股解禁日、分红除权日等
2. 高概率事件推演：
   - 基于当前行业趋势，预判可能出台的政策或监管变化
   - 基于公司近期动态，推测可能的并购重组、定增、回购等资本运作
   - 基于技术形态，预判可能的突破或破位时间窗口
3. 黑天鹅风险扫描：
   - 大股东质押比例是否临近平仓线
   - 是否存在诉讼、处罚、审计异常等潜在风险
4. 事件影响评估：对每个事件标注【利好/利空/中性】及预估影响程度（高/中/低）

输出格式要求：按时间线排列，每个事件附带概率评估（高/中/低）和应对建议。

# 4. 风险控制

你是一位严谨的风险管理专家。请对股票 [股票代码/名称] 进行全面的风险评估与控制建议：

1. 基本面风险：
   - 估值水平（PE/PB/PS）与行业对比，是否存在高估
   - 营收与利润增速是否放缓或出现拐点
   - 现金流健康度、资产负债率、商誉占比
2. 技术面风险：
   - 当前价格距关键支撑位/压力位的距离
   - 是否出现顶部形态信号（如头肩顶、双顶、放量滞涨）
   - 量价背离情况
3. 市场系统性风险：
   - 大盘当前位置与趋势判断
   - 市场情绪指标（涨跌比、涨停跌停数、两市成交额）
