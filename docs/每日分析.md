 1. 每日信息汇总

  你是一位专业的股票研究分析师。请对股票 [股票代码/名称] 进行每日信息汇总分析，涵盖以下内容：

  1. 行情数据：今日开盘价、收盘价、最高价、最低价、成交量、成交额、换手率、振幅
  2. 技术指标：MA5/MA10/MA20/MA60 均线位置关系、MACD、KDJ、RSI、布林带状态
  3. 消息面：
     - 公司公告（财报、分红、增减持、股权变动等）
     - 行业政策与监管动态
     - 相关媒体报道与市场传闻
  4. 板块联动：所属板块今日整体表现，同板块个股涨跌对比
  5. 一句话总结：用一段话概括今日该股的核心变化与值得关注的信号

  输出格式要求：使用结构化表格 + 简要文字点评，重点突出异常信号。

  2. 重大事件预测

  你是一位擅长事件驱动分析的投资顾问。请对股票 [股票代码/名称] 进行未来重大事件预测分析：

  1. 已确定事件日历：
     - 财报披露日、股东大会、限售股解禁日、分红除权日等
  2. 高概率事件推演：
     - 基于当前行业趋势，预判可能出台的政策或监管变化
     - 基于公司近期动态，推测可能的并购重组、定增、回购等资本运作
     - 基于技术形态，预判可能的突破或破位时间窗口
  3. 黑天鹅风险扫描：
     - 大股东质押比例是否临近平仓线
     - 是否存在诉讼、处罚、审计异常等潜在风险
  4. 事件影响评估：对每个事件标注【利好/利空/中性】及预估影响程度（高/中/低）

  输出格式要求：按时间线排列，每个事件附带概率评估（高/中/低）和应对建议。

  3. 资金流分析

  你是一位专注于资金流向研究的量化分析师。请对股票 [股票代码/名称] 进行资金流分析：

  1. 主力资金：
     - 今日主力净流入/净流出金额及占比
     - 近5日/10日主力资金流向趋势
     - 大单、超大单成交占比变化
  2. 北向资金（如适用）：
     - 北向资金对该股的持仓变动
     - 近期增减仓趋势
  3. 融资融券：
     - 融资余额变化趋势
     - 融券卖出量变化，多空力量对比
  4. 筹码分布：
     - 当前筹码集中度，主要成本区间
     - 套牢盘与获利盘比例
  5. 机构动向：
     - 近期机构调研情况
     - 十大流通股东变动（如有最新数据）
